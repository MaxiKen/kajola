# 5.2 — Hand-Specimen ID & Field Tests

You can identify most minerals with simple tools: a **10× hand lens**, a **steel knife**,
a **streak plate** (unglazed porcelain), a **hand magnet**, and **dilute HCl**.

## The core tests

| Test | How | What it tells you |
|------|-----|-------------------|
| **Hand lens (10×)** | Look for crystal faces, cleavage, grain shape | Habit, mineral ID |
| **Hardness (Mohs)** | Scratch with fingernail (~2.5), coin (~3), knife (~5.5), glass (~5.5) | Distinguishes soft vs hard |
| **Streak** | Rub on unglazed porcelain | Powder colour (e.g. hematite = red-brown) |
| **Lustre** | Metallic, submetallic, vitreous, pearly, silky, resinous, earthy | Ore vs gangue |
| **Cleavage / fracture** | Break along planes (cleavage) vs irregular (fracture) | Mica (perfect), quartz (conchoidal) |
| **Density / heft** | Feel the weight; "heft" the specimen | Heavy = galena, cassiterite, barite, magnetite |
| **Magnetism** | Hand magnet | Magnetite (and pyrrhotite) |
| **Acid (dil. HCl)** | Drop on fresh surface | Fizz = carbonate (calcite, limestone) |
| **Taste** | *Caution* — only if sure | Halite = salty |
| **Odour** | Scratch/rub | Some clays smell "earthy" |

## Quick-ID for key Nigerian minerals

| Mineral | Key field clues |
|---------|-----------------|
| **Gold** | Soft, heavy, metallic, yellow, malleable (not brittle), no streak on porcelain |
| **Cassiterite** | Very hard, very heavy, brown-black, resinous; in pegmatite/placer |
| **Columbite–tantalite** | Heavy, black, submetallic; in pegmatite |
| **Galena** | Very heavy, metallic grey, perfect cubic cleavage, low hardness |
| **Sphalerite** | Resinous, yellow-brown, lighter than galena |
| **Hematite / magnetite** | Red-brown vs black & magnetic |
| **Pyrite** | Pale brassy-yellow, hard (sparks on steel); "fool's gold" |
| **Chalcopyrite** | Brassy, often tarnished iridescent |
| **Calcite / limestone** | Fizzes in dilute HCl |
| **Quartz** | Very hard, glassy, conchoidal fracture, no cleavage |
| **Kaolin / clay** | Soft, earthy, white, stains hands |
| **Gypsum** | Very soft (fingernail-scratchable), clear/white, no fizz |
| **Micas** | Perfect one-direction cleavage, elastic sheets |
| **Tourmaline (schorl)** | Black, prismatic, striated; in pegmatite/schist |

## Fool's-gold pitfalls
- **Pyrite vs gold:** pyrite is hard & brittle (breaks/gives green-black powder); gold is soft & malleable.
- **Chalcopyrite vs gold:** chalcopyrite is greenish-brass & brittle.
- **Mica vs gold:** biotite/gold-sheen mica flakes are brownish and break into sheets.
