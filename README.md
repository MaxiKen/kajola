# Geology & Mineral Resources of Nigeria

A comprehensive, **illustration-heavy field handout** for exploration geologists
in Nigeria — taking you from the **basics to expert** level, with the emphasis on
**identifying** the rocks and minerals you'll actually meet in the field.

Everything is plain **Markdown** with pictures saved under `assets/images/`, so it
opens in any editor or Markdown viewer, and ports cleanly to a docs site
(MkDocs/Docusaurus) if you want a rendered version later.

## Start here

- 📑 **[`CONTENTS.md`](CONTENTS.md)** — the master table of contents (start here!)
- `00-fundamentals/` — the basics (minerals, rocks, rock cycle, geologic time)
- `01-general-geology/` — the geology of Nigeria, the big picture
- `02-rocks-of-nigeria/` — every rock type, one by one, with profiles & states
- `03-mineral-resources/` — every mineral, with pure + in-rock images & states
- `04-geological-provinces/` — where things are, belt by belt, state by state
- `05-field-identification/` — hand-specimen ID, field tests, exploration notes
- `06-references/` — key references, maps, and how to grow this handout

## Conventions

- **One rock or mineral per file**, using the standard profile template (see
  `CONTENTS.md`).
- **Every profile is illustrated** — a pure/hand-specimen image *and* an image of
  how it occurs in rock or ore. Each figure carries a **source credit**.
- **Cross-link** notes with relative paths, e.g. `[Cassiterite](03-mineral-resources/metallic/cassiterite.md)`.
- **Verify localities** against NGGS maps and GSN bulletins before relying on them
  in the field.

> Sections are being written out in the order given in `CONTENTS.md`.
